# 모두의 음악숲 · 초록숨 기록

강사 1인이 가상 데이터로 수업 기록 설계를 검증하는 한국어 모바일 웹 앱입니다.

## 실행

Node.js 24에서 확인했습니다. 앱 실행에는 외부 패키지가 필요 없습니다.

```sh
cd /workspace/musicmate
npm start
```

서버 포트는 기본 3000이며 `PORT=다른번호 npm start`로 변경합니다. 휴대폰에서는 이 서버에 접근 가능한 호스트 주소를 브라우저로 열어야 합니다. 이 작업에서는 공개 배포를 하지 않았습니다. HTTPS를 지원하는 정적 호스팅에 `index.html`, `app.js`, `core.js`, `db.js`, `styles.css`를 함께 배치해도 동작합니다.

## 사용

1. A01 카드에서 **새 기록** → **예시 원문 넣기** → **정리하기**.
2. 점수와 근거, SOAP를 확인합니다. 점수 버튼·비움 버튼으로 수정하고 서술은 직접 편집합니다. 바꾼 표현은 되돌릴 수 있습니다.
3. 확인란 선택 → **확정하고 저장하기** → 기록 이력에서 회차와 추이를 확인합니다.
4. 회차를 열면 강사 확정본·AI 초안·원문·항목별 수정 이력을 따로 볼 수 있습니다.

예정 회차는 시험용으로 A01 2회, B02 1회입니다. 프로파일에서 수정합니다. A01 1회차는 예시 확정본으로 초기 저장됩니다. 첫 실행 초기화만 예외로 수행하며, 이후 작성 중인 기록은 확정 전 저장하지 않습니다.

## AI와 개인정보 처리

- **실제 AI 연결이 없는 예시 기반 시연 모드**입니다. A01 예시와 일치하는 텍스트에는 사전 작성 JSON 초안을 사용합니다. 다른 원문은 빈 검토 양식을 제공해 강사가 직접 작성합니다. 예시를 실제 AI 출력으로 표시하지 않습니다.
- `core.js`의 `AI_INSTRUCTIONS`에 요청한 AI 규칙을 보관합니다. `organize`는 가린 수업 텍스트만 받으며 프로파일은 받지 않습니다. 실제 연결을 추가할 때도 서버 측 인증과 JSON 검증이 별도로 필요합니다.
- 설정에 `이름=코드`로 이름을 등록합니다. 정확히 일치하는 이름을 긴 이름부터 한 번에 치환합니다. 미등록 이름·오타·별칭은 자동 탐지하지 않습니다.
- 근거 검사는 가린 원문과 공백을 정규화해 대조합니다. 원문에 없거나 점수에 근거가 없으면 확인 필요를 표시합니다. 근거가 있어도 빈도를 추정할 수 없으면 빈 점수를 유지합니다.
- 앱에서 외부 서비스 요청을 하지 않습니다. 외부 폰트·분석 도구·녹음·파일 업로드·메일·공유 기능이 없습니다.

## 저장 및 제한

IndexedDB `musicmate-pilot`에 프로파일·이름 가리기 설정·확정 기록을 저장합니다. 확정 원문, 가린 텍스트, 초기 초안, 최종본, 항목별 수정 여부, 수정 과정, 확정 시각을 분리합니다. 확정 기록은 추가 전용이며 같은 수강생의 회차를 중복 저장할 수 없습니다. 수강생 내부 ID는 고정해 표시 코드를 고쳐도 이력 연결을 유지합니다.

같은 기기·브라우저·앱 주소에서는 브라우저를 닫아도 데이터가 남습니다. 브라우저 데이터 삭제, 저장 공간 회수, 시크릿 모드 종료 등으로 소실될 수 있습니다. 동기화나 백업·내보내기는 제공하지 않습니다. 주소/포트를 바꾸면 별도 저장소가 됩니다. 확정 전 내용은 메모리에만 있어 새로고침·닫기·이동 시 사라집니다. 저장 실패 시 작성 내용은 유지하고 오류를 표시합니다.

가상 데이터 시험용입니다. 로그인·서버 데이터베이스·실제 AI 서비스는 포함하지 않습니다. 기록 화면의 'AI 그대로'는 예시 초안과 최종본이 같은 경우를 뜻하고, 화면에 예시 모드를 함께 표시합니다.

## 검증

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run test:e2e
```

브라우저 테스트는 별도로 `npm start`가 실행 중이어야 하며 `/usr/bin/chromium`을 사용합니다. Playwright는 개발용 의존성입니다. 모바일 화면 크기 390×844에서 입력 → 확인·수정 → 확정 → 이력, 원문 보존, 초안 분리, 빈 점수, 근거 불일치, 표현 되돌리기, 이름 가리기, 미확정 미저장, 새로고침 보존, 중복 회차 방지를 검증합니다. 실행 화면은 `test-results/`에 저장됩니다.
